# Making stuff for LX

Fork it and change whatever you want to work on. If you fix something and want it in this repo, open a pull request and say what you changed and how you tested it.

If something breaks, open an issue with what you were doing, what happened and any error you got. Leave out passwords, tokens and anything private.

Plugins are welcome too. Put yours in a public repo so people can actually find it, read it and use it. Include how to run it and anything it needs. Please don't hide what your code does.

You can share your fork or plugin in [LX's server](https://discord.gg/ygMePuFfYF).

LX All Knowing is private. Don't include it in forks, pull requests or plugin uploads.
